# Valg Lokalt
**Demokratiet, forklart.**

Nasjonal, uavhengig folkeopplysningsplattform for lokaldemokrati. Ålesund er første pilotkommune.

## Status
Versjon 6 – interaktiv utviklingsprototype. Ikke offisielt valgnettsted. Ikke klar for offentlig lansering.

- `index.html`: selvstendig nettside med læringsplansjer, kommunestyre, mandatkalkulator, valgskole og kandidatkåring.
- `election-alesund-2023.json`: 342 kandidater, 14 lister og 47 innvalgte; 23 786 personstemmer og 3 981 slengere. Sammenkoblet på parti og navn fra Valgdirektoratets to Excel-filer for kommunevalget 2023. Fødselsår, ikke fødselsdato. Endelig rangering med kildens forbehold om senere endringer.

Historisk valgresultat 2023 er ikke en oppdatert medlemsliste. Fullstendig formannskap, tidligere valg, yrkesbakgrunn og valglister 2027 gjenstår. Bruksrett og offisiell utforming av kommunevåpenet må avklares før lansering. Samme redaksjonelle regler for alle kandidater.

## Lokal forhåndsvisning
Åpne `index.html` i nettleseren. Ingen byggesteg eller avhengigheter.

## Planlagt publisering
Cloudflare Pages, eget prosjekt, produksjonsgren `main`, ingen byggekommando, rotmappen som output. Eget domene: valglokalt.no. Ingen Netlify. Ikke koblet til domenet ennå.

Kildekoden er offentlig tilgjengelig; lisens for gjenbruk er ikke avklart. Ikke legg passord, API-nøkler eller upubliserte personopplysninger her.
